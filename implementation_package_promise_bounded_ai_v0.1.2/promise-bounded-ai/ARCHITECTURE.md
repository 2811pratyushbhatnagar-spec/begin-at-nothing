# Architecture

## Release line

AI agents do not just need orchestration. They need promises.

## Purpose

This architecture helps humans and builders shape AI action before execution.

It asks:

- What situation is being placed before intelligence acts?
- What promise authorizes the action?
- What boundary limits what may be touched?
- What cost is being created or displaced?
- What trace will remain?
- What repair path exists if the action fails?

## The six kernel objects

### 1. Context

How the situation is placed before AI acts.

Context prevents panic, urgency, identity, or one fragment from becoming the whole.

### 2. Promise

What the agent is authorized to pursue.

A promise is not vague intent. It is a bounded commitment through time.

### 3. Boundary

What the agent may access, affect, reveal, store, change, or escalate.

Boundary is the anti-surveillance layer.

### 4. Trace

What happened, why it happened, and what remains.

Trace is not total memory. It is the minimum record needed for accountability and repair.

### 5. Cost

What continuity required.

Cost includes compute, money, privacy, attention, energy, ecology, labor, emotion, trust, and future repair.

### 6. Repair

What happens if the action fails, harms, exceeds scope, or becomes unclear.

Repair makes failure survivable.

## Minimum action contract

An AI action is not promise-bounded unless it contains:

```json
{
  "context": {},
  "promise": {},
  "boundary": {},
  "cost": {},
  "trace": {},
  "repair": {}
}
```

## Execution rule

In v0.1, nothing executes.

A future runtime may execute only after:

1. The user authorizes the promise.
2. The boundary is explicit.
3. The cost budget is declared.
4. The trace requirement is accepted.
5. The repair path is available.
6. The action remains inside scope.

## Anti-capture principle

The architecture must never allow any part to impersonate the whole.

- A ledger is not the person.
- A market is not value.
- An AI is not authority.
- A trace is not total truth.
- A promise is not ownership.
- A global layer is not private life.
