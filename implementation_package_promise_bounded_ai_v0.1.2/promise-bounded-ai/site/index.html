The kernel

A promise defines why an agent acts. A boundary defines what it may touch. A trace records what happened. A cost shows what continuity required. Repair protects the world when action fails.

v0.1 boundary

This package does not run autonomous agents. It does not connect to tools. It does not track, store, or send personal data. It is a static artifact for clarity, validation, and sharing.

Freeze line: Promise-Bounded AI v0.1 is not an autonomous agent system. It is an open alignment architecture for shaping, bounding, validating, and repairing AI action before execution.
