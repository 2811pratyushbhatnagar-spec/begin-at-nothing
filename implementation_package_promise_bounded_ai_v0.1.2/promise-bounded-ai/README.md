# Promise-Bounded AI Architecture v0.1

**An open design for agents that act through promises, boundaries, traces, costs, and repair.**

AI agents do not just need orchestration. They need promises.

A promise defines why an agent acts.  
A boundary defines what it may touch.  
A trace records what happened.  
A cost shows what continuity required.  
Repair protects the world when action fails.

This package is a static, inspectable, local-first alignment architecture. It is not an autonomous agent runtime.

## Fastest use

Give your AI a better starting point.

Upload `AI_CONTEXT_SEED.md` or paste it into your AI's custom instructions, project instructions, or agent system prompt.

It teaches the AI to place a situation before answering:

- What is here?
- What boundary is affected?
- What promise is involved?
- What trace remains?
- Who carries the cost?
- What repair is possible?
- What is the smallest truthful next move?

## What this package contains

- A human-facing **Nothing Navigator** for shaping context before asking AI.
- A **Promise Builder** demo for turning messy requests into bounded action plans.
- JSON schemas for Context, Promise, Boundary, Trace, Cost, Repair, and Governance.
- AI and human instructions for promise-bounded action.
- Examples of valid, incomplete, community, and blocked actions.
- Anti-capture and privacy rules.

## Core rule

No agent action should execute unless it has:

1. an authorized promise,
2. a declared boundary,
3. a cost budget,
4. a trace requirement,
5. a repair path.

## v0.1 boundary

This release is for clarity, validation, and sharing.

It does **not** execute autonomous actions.  
It does **not** connect to external services.  
It does **not** store personal data.  
It does **not** use analytics or tracking.  
It does **not** ask anyone to believe a framework.
