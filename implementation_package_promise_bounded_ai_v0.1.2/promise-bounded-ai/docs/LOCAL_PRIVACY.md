# Local Privacy

v0.1 is designed to run as static files.

It should not use:

- analytics,
- accounts,
- cookies,
- remote fonts,
- third-party scripts,
- remote storage,
- hidden telemetry.

The Navigator and Promise Builder should work locally in the browser.

Copy buttons should copy only what the user chooses.

No data should leave the device unless the user intentionally pastes or sends it elsewhere.
