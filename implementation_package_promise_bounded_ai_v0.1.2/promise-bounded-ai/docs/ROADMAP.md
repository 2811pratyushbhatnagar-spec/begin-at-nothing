# Roadmap

## Phase 1 — Static Public Package

Goal: make promise-bounded AI understandable and inspectable.

Includes README, architecture, schemas, instructions, examples, and local static site.

## Phase 2 — Interactive Demo

Goal: show the idea without autonomous execution.

Includes Nothing Navigator and Promise Builder.

## Phase 3 — Validation Layer

Goal: allow builders to validate promise-bound action objects.

Add schema validation and blocked-action examples.

## Phase 4 — Runtime Prototype

Do not start here.

A future runtime should follow:

User request
→ Context intake
→ Promise draft
→ Boundary check
→ Cost budget
→ Trace preview
→ Repair path
→ Human authorize
→ Action allowed
