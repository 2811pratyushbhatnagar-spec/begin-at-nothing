# Promise Field World Packet v0.1

**From nothing to promise, context, AI alignment, navigator, and ledger.**

This is a public-facing packet for sharing the work in a clean register.

It contains:

1. **Source Bootstrap** — the logical construction from nothing to promise-field.
2. **Context + Navigator** — tools for shaping a situation before action.
3. **Promise-Bounded AI** — an open architecture for agents that act through promises, boundaries, traces, costs, and repair.
4. **Open Promise Ledger** — a design proposal for consent-bounded economic/governance infrastructure.
5. **Implementation package** — the current static website/package v0.1.2.

## Core line

To describe anything consistently, something must hold.

That holding is promise-like.

Once affected boundaries enter the field, promise requires trace, cost, care, and repair.

## What this is

A research booklet, design packet, and open-source seed.

It is meant to be read, tested, forked, criticized, implemented locally, and improved.

## What this is not

This is not a completed theory of everything.

It does not claim that all physics is derived here.

It does not claim that AI alignment is solved.

It does not claim that harmony is guaranteed.

It does not ask for belief.

It offers a construction and a set of artifacts for testing.
